## ActivityFeed Changes

### Container: left accent border
```tsx
<div className="bg-surface border border-border border-l-2 border-l-primary rounded-lg overflow-hidden">
```
Wait — Tailwind doesn't compose border-color overrides cleanly with shorthand.
Use `border border-border` + explicit left-border override:
```tsx
<div className="bg-surface rounded-lg overflow-hidden"
     style={{ border: '1px solid #252538', borderLeft: '2px solid #7c3aed' }}>
```
Or use Tailwind 4 approach:
```tsx
<div className="bg-surface border border-border rounded-lg overflow-hidden [border-left:2px_solid_#7c3aed]">
```
Actually simplest: use className with specific border classes:
```tsx
<div className="bg-surface border-y border-r border-border border-l-2 border-l-primary rounded-lg overflow-hidden">
```

### Header: live indicator
```tsx
<div className="px-4 py-3 border-b border-border flex items-center gap-2">
  <span className="relative flex h-2 w-2" aria-hidden="true">
    <span className="animate-ping absolute inline-flex h-full w-full rounded-full bg-green-400 opacity-75" />
    <span className="relative inline-flex rounded-full h-2 w-2 bg-green-400" />
  </span>
  <h3 className="text-sm font-medium text-gray-300">En vivo</h3>
</div>
```

### Step bullets: larger + pulse on latest
```tsx
// For all steps:
<div className={`mt-1.5 w-2 h-2 rounded-full flex-shrink-0 ${
  isLast ? 'bg-primary animate-pulse' : 'bg-primary/60'
}`} aria-hidden="true" />
```

`isLast` = `index === steps.length - 1`
