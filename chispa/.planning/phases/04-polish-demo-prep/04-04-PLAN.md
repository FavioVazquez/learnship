# Plan 04: Final Polish — Health Endpoint, Smooth Scroll, Empty State

## Objective

Three small but demo-critical polish tasks applied across two files. First, `/api/health` gains `uptime`, `version`, and `nodeVersion` fields — useful during a conference demo to quickly verify the server is live. Second, `Dashboard.tsx` gains a `useEffect` that scrolls smoothly into view when analysis completes — at a conference on a phone or small laptop, results below the fold are invisible without this. Third, Dashboard handles the `competitors.length === 0` case with a Spanish message instead of a blank section — the current code correctly hides the competitor list when empty but shows nothing in its place.

This plan is `single_layer_justified: true` because it is a pure polish pass — small additive tweaks across components, no new user-facing behaviors requiring full vertical slices.

## Context

`server/src/routes/index.ts` currently returns `{ status, model, timestamp }` from `/api/health`. Adding `uptime: process.uptime()`, `version: "1.0.0"`, and `nodeVersion: process.version` is purely additive — no callers depend on the exact shape.

`client/src/components/Dashboard.tsx` currently has no scroll behavior — it mounts and renders in place. On mobile or narrow viewports, the Dashboard renders below the IdeaForm and ActivityFeed summary, putting the verdict card below the fold. A single `useEffect` with a `ref.scrollIntoView({ behavior: 'smooth' })` call fixes this.

`Dashboard.tsx` already has `{result.competitors.length > 0 && (...)}` which correctly hides the competitor section for empty arrays. The fix is to add an `else` branch with a card showing "No se encontraron competidores directos — eso puede ser una ventaja."

All styling uses existing Tailwind color tokens: `bg-surface`, `border-border`, `text-gray-400`, `text-gray-500`. No new color values.
