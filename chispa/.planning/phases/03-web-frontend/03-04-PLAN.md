# Plan 04: CompetitorCard + MarketSnapshot + FirstSteps

## Objective

Build the three secondary dashboard components: CompetitorCard shows each competitor with favicon and optional funding badge; MarketSnapshot shows market size, growth, and a Spanish-labeled timing badge; FirstSteps shows a numbered action list only when the verdict is LAUNCH or VALIDATE. All three are standalone components renderable with hardcoded props to verify them visually before Dashboard wires them together.

## Context

This plan runs in parallel with Plan 03 (Dashboard/RadarChart/VerdictCard) — both are Wave 2 and share no files. The canonical types are in `client/src/types/analysis.ts`: `Competitor` has `name`, `description`, `funding?`, `founded?`, `website?`; `AnalysisResult` has `marketSize`, `marketGrowth`, `marketTiming` (`'too_early' | 'right_time' | 'too_late'`), `firstSteps: string[]`, `verdict`. Key pitfall from RESEARCH.md: Google favicon `<img>` needs an `onError` handler to hide the image if the request fails (CSP or network block) — not just a conditional render when `website` is missing. Tailwind color tokens: `bg-surface`, `border-border`, `text-primary`, `text-primary-light`. Spanish copy throughout.

```typescript
import type { Competitor } from '../types/analysis'

interface CompetitorCardProps {
  competitor: Competitor
}

export function CompetitorCard({ competitor }: CompetitorCardProps) {
  const { name, description, funding, website } = competitor

  return (
    <div className="bg-surface border border-border rounded-xl p-5 flex flex-col gap-3">
      {/* Header: favicon + name */}
      <div className="flex items-center gap-3">
        {website && (
          <img
            src={`https://www.google.com/s2/favicons?domain=${website}&sz=32`}
            alt=""
            width={20}
            height={20}
            className="rounded-sm flex-shrink-0"
            onError={(e) => {
              ;(e.target as HTMLImageElement).style.display = 'none'
            }}
          />
        )}
        <h4 className="font-semibold text-white text-sm leading-tight">{name}</h4>
      </div>

      {/* Description */}
      <p className="text-gray-400 text-sm leading-relaxed">{description}</p>

      {/* Funding badge — only when present */}
      {funding && (
        <div className="mt-auto">
          <span className="inline-flex items-center px-2.5 py-1 rounded-full text-xs font-medium bg-primary/20 text-primary-light border border-primary/30">
            {funding}
          </span>
        </div>
      )}
    </div>
  )
}
```

Implementation notes:
- Favicon `<img>` renders ONLY when `website` is truthy — prevents a broken `https://www.google.com/s2/favicons?domain=undefined&sz=32` request
- `onError` handler sets `display: 'none'` on the img element — handles the case where the website exists but Google's favicon API fails (CSP block, network error, unknown domain)
- `alt=""` is intentional — the favicon is decorative; screen readers should skip it
- `funding` badge uses `mt-auto` to push it to the bottom of the card when description lengths vary across cards in a grid
- `bg-primary/20` and `border-primary/30` use Tailwind opacity modifiers — no raw hex needed in class names

```typescript
        </div>

        {/* Timing badge */}

```

Implementation notes:
- `TIMING_CONFIG` maps all three `marketTiming` enum values to Spanish labels and colors per CONTEXT.md spec:
  - `too_early` → "Demasiado temprano" (amber)
  - `right_time` → "Momento perfecto" (green)
  - `too_late` → "Demasiado tarde" (red)
- The timing badge uses inline `style` for color/bg — required because the hex values are dynamic and Tailwind can't purge-safe-guard arbitrary dynamic colors
- `border: \`1px solid ${timing.color}40\`` appends `40` hex alpha (25% opacity) for a subtle colored border matching the VerdictCard pattern
- Card height matches RiskRadarChart (both in a 2-col grid) via `flex flex-col` — content flows top-to-bottom without forced height

```typescript
import type { AnalysisResult } from '../types/analysis'

interface FirstStepsProps {
  verdict: AnalysisResult['verdict']
  firstSteps: string[]
}

export function FirstSteps({ verdict, firstSteps }: FirstStepsProps) {
  // Only render for actionable verdicts — PIVOT and AVOID don't get next steps
  if (verdict !== 'LAUNCH' && verdict !== 'VALIDATE') return null
  if (firstSteps.length === 0) return null

  return (
    <div className="bg-surface border border-border rounded-xl p-6">
      <h3 className="text-sm font-medium text-gray-300 uppercase tracking-widest mb-5">
        Primeros pasos
      </h3>
      <ol className="space-y-4">
        {firstSteps.slice(0, 5).map((step, index) => (
          <li key={index} className="flex items-start gap-4">
            <span
              className="flex-shrink-0 w-7 h-7 rounded-full bg-primary/20 border border-primary/40 flex items-center justify-center text-xs font-bold text-primary-light"
            >
              {index + 1}
            </span>
            <p className="text-gray-200 text-sm leading-relaxed pt-0.5">{step}</p>
          </li>
        ))}
      </ol>
    </div>
  )
}
```

Implementation notes:
- Returns `null` when verdict is `'PIVOT'` or `'AVOID'` — these outcomes don't warrant next steps (CONTEXT.md spec)
- Returns `null` when `firstSteps` array is empty — defensive guard for malformed API responses
- `slice(0, 5)` caps at 5 steps per CONTEXT.md spec; Claude's prompt requests 5 but may return more or fewer
- Step number circle uses `bg-primary/20` + `border-primary/40` + `text-primary-light` — consistent with the funding badge and source badge color pattern from other components
- `pt-0.5` on the paragraph aligns text baseline with the center of the number circle
