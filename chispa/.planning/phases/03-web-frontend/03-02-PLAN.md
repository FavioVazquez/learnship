# Plan 02: IdeaForm + ActivityFeed Components

## Objective

Build the two input/output components that bracket the analysis flow: IdeaForm collects the startup idea and submits it; ActivityFeed displays Claude's live tool-call steps as they stream in. Both components are self-contained and can be rendered with hardcoded props in App.tsx to verify they work visually before wiring to the hook in Plan 05.

## Context

`AppState` is defined in `client/src/hooks/useAnalysis.ts` (Plan 01 output — this plan can proceed in parallel since the type is known). `SSEMessage` step type is `{ type: 'step'; text: string; source?: string }` from `client/src/types/analysis.ts`. framer-motion 12 is installed after Plan 01's package upgrade task. Key constraint: `staggerChildren` is deprecated in framer-motion 12 — use `delayChildren: stagger(0.08)` from `import { motion, stagger } from 'framer-motion'`. Tailwind color tokens: `bg-surface` (#13131a), `border-border` (#1f1f2e), `text-primary` (#7c3aed), `bg-background` (#0a0a0f). Spanish labels throughout.

```typescript
import { useState, FormEvent } from 'react'
import { Loader2 } from 'lucide-react'
import type { AppState } from '../hooks/useAnalysis'

interface IdeaFormProps {
  state: AppState
  onSubmit: (idea: string, country?: string) => void
}

const COUNTRY_OPTIONS = [
  { value: '', label: 'Selecciona un país (opcional)' },
  { value: 'Guatemala', label: 'Guatemala' },
  { value: 'México', label: 'México' },
  { value: 'Colombia', label: 'Colombia' },
  { value: 'Argentina', label: 'Argentina' },
  { value: 'España', label: 'España' },
  { value: 'Otro', label: 'Otro' },
]

export function IdeaForm({ state, onSubmit }: IdeaFormProps) {
  const [idea, setIdea] = useState('')
  const [country, setCountry] = useState('')
  const [validationError, setValidationError] = useState<string | null>(null)

  const isDisabled = state === 'streaming' || state === 'complete'
  const isStreaming = state === 'streaming'
  const charCount = idea.length

  const handleSubmit = (e: FormEvent) => {
    e.preventDefault()
    setValidationError(null)

    if (idea.trim().length < 20) {
      setValidationError('Tu idea debe tener al menos 20 caracteres.')
      return
    }
    if (idea.trim().length > 500) {
      setValidationError('Tu idea no puede superar los 500 caracteres.')
      return
    }

    onSubmit(idea.trim(), country || undefined)
  }

  return (
    <form onSubmit={handleSubmit} className="w-full max-w-2xl mx-auto space-y-4">
      <div className="space-y-2">
        <label htmlFor="idea" className="block text-sm font-medium text-gray-300">
          Describe tu idea de negocio
        </label>
        <textarea
          id="idea"
          value={idea}
          onChange={(e) => setIdea(e.target.value)}
          disabled={isDisabled}
          minLength={20}
          maxLength={500}
          rows={5}
          placeholder="Ej: Una plataforma de delivery de comida saludable para oficinas en Ciudad de Guatemala, con suscripciones semanales y opciones veganas..."
          className="w-full bg-surface border border-border rounded-lg px-4 py-3 text-white placeholder-gray-500 resize-none focus:outline-none focus:ring-2 focus:ring-primary focus:border-transparent disabled:opacity-50 disabled:cursor-not-allowed transition-opacity"
        />
        <div className="flex justify-between items-center">
          <span className={`text-xs ${charCount < 20 ? 'text-gray-500' : charCount > 450 ? 'text-amber-400' : 'text-gray-400'}`}>
            {charCount}/500 caracteres
          </span>
          {validationError && (
            <span className="text-xs text-red-400">{validationError}</span>
          )}
        </div>
      </div>

      <div className="space-y-2">
        <label htmlFor="country" className="block text-sm font-medium text-gray-300">
          País objetivo
        </label>
        <select
          id="country"
          value={country}
          onChange={(e) => setCountry(e.target.value)}
          disabled={isDisabled}
          className="w-full bg-surface border border-border rounded-lg px-4 py-3 text-white focus:outline-none focus:ring-2 focus:ring-primary focus:border-transparent disabled:opacity-50 disabled:cursor-not-allowed appearance-none"
        >
          {COUNTRY_OPTIONS.map((opt) => (
            <option key={opt.value} value={opt.value}>
              {opt.label}
            </option>
          ))}
        </select>
      </div>

      <button
        type="submit"
        disabled={isDisabled}
        className="w-full bg-primary hover:bg-primary-light disabled:opacity-50 disabled:cursor-not-allowed text-white font-semibold py-3 px-6 rounded-lg transition-colors flex items-center justify-center gap-2"
      >
        {isStreaming ? (
          <>
            <Loader2 className="w-5 h-5 animate-spin" />
            Analizando...
          </>
        ) : (
          'Analizar mi idea'
        )}
      </button>
    </form>
  )
}
```

Notes:
- Validation runs on submit, not on keypress — matches CONTEXT.md spec
- `country || undefined` converts empty string to `undefined` so the hook receives `undefined` for no country, not an empty string
- Char counter changes color: gray when under 20 (not yet valid), amber when above 450 (approaching limit), green-gray otherwise
- `disabled:opacity-50` and `disabled:cursor-not-allowed` on all interactive elements when state is streaming or complete

```typescript
import { useEffect, useRef } from 'react'
import { motion } from 'framer-motion'
import type { SSEMessage } from '../types/analysis'

type StepMessage = Extract<SSEMessage, { type: 'step' }>

interface ActivityFeedProps {
  steps: StepMessage[]
}

export function ActivityFeed({ steps }: ActivityFeedProps) {
  const bottomRef = useRef<HTMLDivElement>(null)

  // Auto-scroll to bottom when new steps arrive
  useEffect(() => {
    bottomRef.current?.scrollIntoView({ behavior: 'smooth' })
  }, [steps.length])

  if (steps.length === 0) {
    return (
      <div className="w-full max-w-2xl mx-auto">
        <div className="bg-surface border border-border rounded-lg p-6">
          <div className="flex items-center gap-3">
            <div className="w-2 h-2 bg-primary rounded-full animate-pulse" />
            <span className="text-gray-400 text-sm">Iniciando análisis...</span>
          </div>
        </div>
      </div>
    )
  }

  return (
    <div className="w-full max-w-2xl mx-auto">
      <div className="bg-surface border border-border rounded-lg overflow-hidden">
        <div className="px-4 py-3 border-b border-border">
          <h3 className="text-sm font-medium text-gray-300">Actividad en tiempo real</h3>
        </div>
        <div className="max-h-64 overflow-y-auto p-4 space-y-3">
          {steps.map((step, index) => (
            <motion.div
              key={index}
              initial={{ opacity: 0, x: -8 }}
              animate={{ opacity: 1, x: 0 }}
              transition={{
                duration: 0.3,
                delay: 0,
                ease: 'easeOut',
              }}
              className="flex items-start gap-3"
            >
              <div className="mt-1.5 w-1.5 h-1.5 bg-primary rounded-full flex-shrink-0" />
              <div className="flex-1 min-w-0">
                <span className="text-sm text-gray-200">{step.text}</span>
                {step.source && (
                  <span className="ml-2 inline-flex items-center px-1.5 py-0.5 rounded text-xs font-medium bg-primary/20 text-primary-light border border-primary/30">
                    {step.source}
                  </span>
                )}
              </div>
            </motion.div>
          ))}
          <div ref={bottomRef} />
        </div>
      </div>
    </div>
  )
}
```

Implementation notes:
- Each step item uses `motion.div` with individual `initial`/`animate` for entrance animation. This approach correctly animates each new item as it arrives, rather than re-animating all items on each render.
- The `stagger` function from framer-motion 12 is imported but the animation is per-item (each new step slides in as it arrives). Container-level stagger would re-animate all existing items when a new step is added — per-item approach is correct for a live feed.
- Auto-scroll uses `useRef` on a sentinel div at the bottom, with `scrollIntoView` triggered by `steps.length` change.
- `max-h-64` + `overflow-y-auto` gives a scrollable window. Global CSS in `index.css` styles the scrollbar with purple thumb automatically.
- `step.source` badge uses `bg-primary/20` (Tailwind opacity modifier) and `text-primary-light` for the source domain label.
- Empty state shows a pulsing dot to indicate the system is alive.

Note on animation pattern: Per-item `motion.div` entrance animation (each step slides in as it arrives) is the correct pattern for a streaming feed. Container-level stagger would re-animate all existing items on each new step — wrong for live data. If a container stagger is ever needed, use `delayChildren: stagger(0.08)` from `import { stagger } from 'framer-motion'` — NOT the deprecated `staggerChildren` variant property.
