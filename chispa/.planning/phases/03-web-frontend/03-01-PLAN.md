# Plan 01: useAnalysis Hook + Package Upgrades

## Objective

Upgrade framer-motion, recharts, and add lz-string in the client, then implement the `useAnalysis()` hook that consumes the `/api/analyze` SSE stream. The hook is the foundation all UI components depend on — it owns the state machine, SSE parsing, and AbortController lifecycle. When this plan is complete, a developer can import and call the hook to observe state changes driven by a live or mock backend.

## Context

The client currently has framer-motion@11.x and recharts@2.x installed — both must be upgraded to their v12/v3 majors before any component code is written, since v12 APIs (stagger function) and v3 Recharts types are used in later plans. lz-string is not yet installed. The SSE server format from Phase 2 is `data: ${JSON.stringify(msg)}\n\n` — the hook must buffer across chunk boundaries, parse complete events, and discriminate on `SSEMessage.type`. React 18 StrictMode double-invokes effects, so `AbortError` must be silently swallowed. The canonical types are in `client/src/types/analysis.ts`.

```typescript
import { useState, useRef, useCallback } from 'react'
import type { SSEMessage, AnalysisResult } from '../types/analysis'

export type AppState = 'idle' | 'streaming' | 'complete' | 'error'

interface UseAnalysisReturn {
  state: AppState
  steps: Extract<SSEMessage, { type: 'step' }>[]
  result: AnalysisResult | null
  error: string | null
  submit: (idea: string, country?: string) => void
  abort: () => void
}

export function useAnalysis(): UseAnalysisReturn {
  const [state, setState] = useState<AppState>('idle')
  const [steps, setSteps] = useState<Extract<SSEMessage, { type: 'step' }>[]>([])
  const [result, setResult] = useState<AnalysisResult | null>(null)
  const [error, setError] = useState<string | null>(null)
  const abortControllerRef = useRef<AbortController | null>(null)

  const abort = useCallback(() => {
    if (abortControllerRef.current) {
      abortControllerRef.current.abort()
      abortControllerRef.current = null
    }
  }, [])

  const submit = useCallback((idea: string, country?: string) => {
    // Cancel any in-flight request
    if (abortControllerRef.current) {
      abortControllerRef.current.abort()
    }

    const controller = new AbortController()
    abortControllerRef.current = controller

    // Reset state for new submission
    setState('streaming')
    setSteps([])
    setResult(null)
    setError(null)

    const run = async () => {
      try {
        const response = await fetch('/api/analyze', {
          method: 'POST',
          headers: { 'Content-Type': 'application/json' },
          body: JSON.stringify({ idea, country }),
          signal: controller.signal,
        })

        if (!response.ok) {
          const text = await response.text()
          setError(`Error ${response.status}: ${text}`)
          setState('error')
          return
        }

        if (!response.body) {
          setError('No response body from server')
          setState('error')
          return
        }

        const reader = response.body.getReader()
        const decoder = new TextDecoder()
        let buffer = ''

        while (true) {
          const { done, value } = await reader.read()
          if (done) break

          buffer += decoder.decode(value, { stream: true })
          const parts = buffer.split('\n\n')
          buffer = parts.pop()!

          for (const part of parts) {
            const trimmed = part.trim()
            if (!trimmed) continue

            for (const line of trimmed.split('\n')) {
              if (!line.startsWith('data: ')) continue
              const jsonStr = line.slice(6)

              let msg: SSEMessage
              try {
                msg = JSON.parse(jsonStr) as SSEMessage
              } catch {
                continue
              }

              if (msg.type === 'step') {
                setSteps((prev) => [...prev, msg as Extract<SSEMessage, { type: 'step' }>])
              } else if (msg.type === 'result') {
                setResult(msg.data)
                setState('complete')
              } else if (msg.type === 'error') {
                setError(msg.message)
                setState('error')
              }
              // type === 'ping': do nothing
            }
          }
        }
      } catch (err) {
        // Silently swallow AbortError — React 18 StrictMode fires cleanup on first mount,
        // and users may call abort() explicitly. Neither case is an error.
        if (err instanceof Error && err.name === 'AbortError') return
        setError(err instanceof Error ? err.message : 'Unknown error')
        setState('error')
      }
    }

    run()
  }, [])

  return { state, steps, result, error, submit, abort }
}
```

Key implementation notes:
- The `AppState` type is exported so other components can import and use it for prop typing
- `steps` is typed as `Extract<SSEMessage, { type: 'step' }>[]` — the discriminated union member, not a looser type
- Buffer pattern: `buffer += chunk; parts = buffer.split('\n\n'); buffer = parts.pop()!` — the trailing `!` is required because `pop()` returns `string | undefined` but we know `split` always produces at least one element
- `AbortError` check uses `err.name === 'AbortError'` because Node.js global `fetch` throws `TypeError` (not `DOMException`) with name set to `'AbortError'`
- `ping` type is explicitly skipped (comment included for clarity)
- `submit` is `useCallback` with empty deps — it does not close over state setters (they are stable)
