# Plan 02-01: SSE Route + Rate Limiter

<objective>
Create `server/src/routes/analyze.ts` as a working SSE endpoint that validates the request body, enforces a 3-concurrent-analyses rate limit synchronously, sets SSE headers and flushes them before any await, then emits a stub step + result response. Wire it into `server/src/routes/index.ts` by removing the 501 stub and mounting the new router. This delivers the full HTTP -> validation -> SSE -> response vertical slice, verifiable with curl -N before the real Claude agent exists.
</objective>

## Context

The codebase uses ESM throughout — all local TypeScript imports must use `.js` extensions (e.g., `'../types/analysis.js'`), even though the files are `.ts`. Missing `.js` causes `ERR_MODULE_NOT_FOUND` at runtime on Node 20+ with tsx.

SSE header ordering is critical (RESEARCH.md Pitfall 3). Validation and rate-limit guard must happen synchronously BEFORE setting headers and calling `res.flushHeaders()`. If validation fails before headers are sent, return a plain JSON error response. The connection is not yet an SSE stream at that point.

The rate-limit check and increment must have no `await` between them (RESEARCH.md Pitfall 6). Node.js cooperative scheduling means any `await` between check and increment creates a race window where two concurrent requests both pass the guard.

TypeScript strict mode is enforced — error catches must use `catch (err: unknown)` and narrow via `err instanceof Error ? err.message : String(err)`.

The 501 stub in `server/src/routes/index.ts` (lines 13-15) must be fully removed — not patched.

The `country` variable from the parsed body should be declared (even if unused in the stub) to avoid breaking Plan 02-03, which adds it to the analyzer call.

   ```ts
   const router = Router()

   router.post('/api/analyze', async (req: Request, res: Response): Promise<void> => {
     // Step 1 — synchronous validation (before SSE headers)
     const body = req.body as { idea?: unknown; country?: unknown }
     const idea = body.idea
     if (typeof idea !== 'string' || idea.length < 20 || idea.length > 500) {
       res.status(400).json({ error: 'El campo "idea" debe tener entre 20 y 500 caracteres.' })
       return
     }
     const country = typeof body.country === 'string' ? body.country : undefined

     // Step 2 — synchronous rate limit check-and-increment (no await between these two lines)
     if (activeAnalyses >= MAX_CONCURRENT) {
       res.status(429).json({ error: 'Demasiados análisis en curso. Intenta en unos segundos.' })
       return
     }
     activeAnalyses++

     // Step 3 — set SSE headers synchronously
     res.setHeader('Content-Type', 'text/event-stream')
     res.setHeader('Cache-Control', 'no-cache')
     res.setHeader('Connection', 'keep-alive')
     res.setHeader('X-Accel-Buffering', 'no')
     res.flushHeaders() // MUST be before any await

     try {
       // Stub: short delay then two SSE events
       await new Promise<void>((resolve) => setTimeout(resolve, 100))

       sendSSE(res, { type: 'step', text: 'Iniciando análisis...', source: 'web_search_20250305' })

       const mockResult: AnalysisResult = {
         competitors: [
           {
             name: 'Competidor Ejemplo S.A.',
             description: 'Empresa líder en el sector con presencia en LatAm.',
             website: 'https://ejemplo.com',
           },
         ],
         marketSize: '$500M USD en LatAm',
         marketGrowth: 'Crecimiento anual del 12%',
         marketTiming: 'right_time',
         risks: [
           {
             title: 'Competencia establecida',
             severity: 'medium',
             mitigation: 'Enfocarse en un nicho diferenciado.',
           },
         ],
         verdict: 'VALIDATE',
         verdictReason: 'El mercado existe pero requiere validación del nicho específico.',
         firstSteps: [
           'Entrevistar a 20 clientes potenciales esta semana.',
           'Construir un landing page con lista de espera.',
           'Definir el segmento de clientes prioritario.',
           'Analizar 3 competidores directos en profundidad.',
           'Estimar el costo de adquisición de cliente (CAC) inicial.',
         ],
         searchedAt: new Date().toISOString(),
       }

       sendSSE(res, { type: 'result', data: mockResult })
     } catch (err: unknown) {
       sendSSE(res, {
         type: 'error',
         message: err instanceof Error ? err.message : String(err),
       })
     } finally {
       activeAnalyses--
       res.end()
     }
   })

   export default router
   ```
