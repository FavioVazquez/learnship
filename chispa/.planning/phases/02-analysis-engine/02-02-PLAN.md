# Plan 02-02: Claude Agent Module

<objective>
Create `server/src/agent/analyzer.ts` — the module that owns all Claude API interaction. It exports a single async generator `analyzeIdea(idea, country?)` that calls Claude claude-opus-4-7 with the web_search_20250305 tool, yields SSEMessage step events as tool calls happen, and yields a final SSEMessage result event after extracting and parsing the JSON from the completed stream. This module is independent of Express — it has no `res` parameter and no SSE headers logic. The route handler (Plan 02-01) owns the HTTP layer; this module owns the AI layer.
</objective>

## Context

The installed Anthropic SDK version is 0.30.1 (confirmed from `server/package.json` and `node_modules`). `client.messages.stream()` exists at this version and returns a `MessageStream` that implements `AsyncIterator`. All stream event types used below were verified against the installed SDK source.

Critical patterns from RESEARCH.md:

**Use `for await` only — no `.on()` listeners** (Pitfall 5): mixing `.on('error', ...)` with `for await` causes double-emit on errors. Use a single `try/catch` around the `for await` loop.

**Use `stream.finalMessage()` — not `stream.finalText()`** (Pitfall 2): `finalText()` joins ALL text blocks with a space, which corrupts JSON if Claude emits any preamble before the JSON block. `finalMessage()` returns the full `Message` object; filter `.content` for `type === 'text'` blocks and take `.at(-1)`.

**Strip markdown fences before JSON.parse** (Pitfall 8): Claude wraps JSON in code fences despite instructions. Strip with regex before parsing.

**Check `stop_reason === 'max_tokens'`** (Pitfall 10): If the response is truncated, `JSON.parse` will throw on incomplete JSON. Detect this before parsing and yield an error SSEMessage.

**Tool name is `web_search_20250305`** (Pitfall 7): The `content_block.name` in stream events matches exactly what was passed in the `tools` array. Emit step events on ANY `tool_use` block start — do not filter by tool name.

**ESM imports**: local imports use `.js` extension; `@anthropic-ai/sdk` is a node_module and needs no extension.

**TypeScript strict mode**: `catch (err: unknown)` required; use `err instanceof Error ? err.message : String(err)`.

The `country` parameter is optional. When provided, it must be interpolated into both the user message and the system prompt instruction about LatAm focus.

export async function* analyzeIdea(
  idea: string,
  country?: string
): AsyncGenerator<SSEMessage> {
  try {
    // Build user message
    const countryContext = country
      ? `\n\nPaís objetivo: ${country}. Prioriza competidores y contexto de mercado en Latinoamérica, especialmente en ${country}.`
      : ''
    const userMessage = `Analiza esta idea de negocio:${countryContext}\n\n${idea}`

    // Start the stream
    const stream = client.messages.stream({
      model: 'claude-opus-4-7',
      max_tokens: 4096,
      system: SYSTEM_PROMPT,
      tools: [{ type: 'web_search_20250305', name: 'web_search' }],
      messages: [{ role: 'user', content: userMessage }],
    })

    let stepCount = 0

    // Process intermediate stream events
    for await (const event of stream) {
      if (
        event.type === 'content_block_start' &&
        event.content_block.type === 'tool_use'
      ) {
        const text = STEP_TEXTS[stepCount % STEP_TEXTS.length]
        stepCount++
        yield {
          type: 'step',
          text,
          source: event.content_block.name,
        }
      }
    }

    // Extract final result after stream completes
    const finalMsg = await stream.finalMessage()

    // Guard against truncated responses
    if (finalMsg.stop_reason === 'max_tokens') {
      yield {
        type: 'error',
        message: 'El análisis fue demasiado largo. Intenta con una idea más concisa.',
      }
      return
    }

    // Extract last text block (NOT finalText() — it joins all blocks with a space)
    const textBlocks = finalMsg.content.filter((b) => b.type === 'text')
    const rawText = textBlocks.at(-1)?.text ?? ''

    // Strip markdown code fences if Claude wrapped the JSON
    const cleaned = rawText
      .replace(/^```(?:json)?\s*/m, '')
      .replace(/\s*```\s*$/m, '')
      .trim()

    const result = JSON.parse(cleaned) as AnalysisResult

    // Ensure searchedAt is set
    if (!result.searchedAt) {
      result.searchedAt = new Date().toISOString()
    }

    yield { type: 'result', data: result }
  } catch (err: unknown) {
    yield {
      type: 'error',
      message: err instanceof Error ? err.message : String(err),
    }
  }
}
```

Note on the `tools` array typing: the `web_search_20250305` tool type may require a type assertion depending on the SDK version. If TypeScript complains about the `type` field, use:
```ts
tools: [{ type: 'web_search_20250305' as const, name: 'web_search' }],
```

Note on `stream.finalMessage()`: this must be called AFTER the `for await` loop completes. The loop drives the stream consumption; `finalMessage()` returns a Promise that resolves once the stream is fully consumed. Calling it before the loop would skip intermediate events.
