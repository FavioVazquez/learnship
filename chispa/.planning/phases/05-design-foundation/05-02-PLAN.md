# Plan 05-02: App Header Redesign

**Phase:** 5 — Design Foundation
**Covers:** UI-04

**Depends on:** 05-01 (font tokens must be in tailwind before using `font-display`)

## Goal

Redesign the App header to be a genuine brand moment. Large Space Grotesk wordmark,
better tagline, subtle depth.

## Tasks

### T1: Redesign App header section (App.tsx)

Replace:
```tsx
<header className="px-6 py-8 text-center">
  <h1 className="text-4xl font-black text-white tracking-tight mb-1">
    ✦ Chispa
  </h1>
  <p className="text-gray-400 text-base">Valida tu idea. En segundos.</p>
</header>
```

With:
```tsx
<header className="relative px-6 pt-14 pb-10 text-center overflow-hidden">
  {/* Subtle radial depth — 8% primary, very blurred */}
  <div
    className="absolute inset-0 pointer-events-none"
    aria-hidden="true"
  >
    <div className="absolute top-0 left-1/2 -translate-x-1/2 w-[600px] h-40
                    bg-primary/[0.08] blur-3xl rounded-full" />
  </div>
  <div className="relative space-y-3">
    <div className="flex items-center justify-center gap-3">
      <span className="text-primary text-3xl leading-none" aria-hidden="true">✦</span>
      <h1 className="font-display text-6xl font-bold text-white tracking-tight">
        Chispa
      </h1>
    </div>
    <p className="text-gray-300 text-lg max-w-sm mx-auto leading-relaxed">
      Valida tu idea de startup con IA.<br />
      <span className="text-gray-500">Real. En segundos.</span>
    </p>
  </div>
</header>
```

## Acceptance Criteria

- [ ] "Chispa" renders in Space Grotesk at ~64px
- [ ] Spark `✦` in primary purple, visually separated from the wordmark
- [ ] Radial glow subtle — does NOT look like neon/glassmorphism
- [ ] Tagline readable at normal viewing distance
- [ ] Header legible at simulated 10-foot projector distance (zoom out to 25%)
- [ ] `npm run typecheck` passes
