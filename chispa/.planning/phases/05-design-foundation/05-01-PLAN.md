# Plan 05-01: Font System + Color Tokens

**Phase:** 5 — Design Foundation
**Covers:** UI-01, UI-02, UI-03, UI-05, UI-06

## Goal

Install the font system and refine the color token set. All subsequent plans depend
on this plan completing first.

## Tasks

### T1: Update index.html — add Google Fonts

Add `preconnect` for Google Fonts domains and load Space Grotesk (700) + Plus Jakarta
Sans (400, 500, 600, 700) with `display=swap`.

**File:** `client/index.html`

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Plus+Jakarta+Sans:wght@400;500;600;700&family=Space+Grotesk:wght@700&display=swap" rel="stylesheet">
```

Remove the existing Inter-only link.

### T2: Update tailwind.config.js — fonts + color tokens

Add font families and updated color tokens.

```js
fontFamily: {
  sans: ['"Plus Jakarta Sans"', 'system-ui', 'sans-serif'],
  display: ['"Space Grotesk"', 'system-ui', 'sans-serif'],
},
colors: {
  background: '#0a0a0f',
  surface: '#0e0e18',           // was #13131a — more distinct from bg
  'surface-elevated': '#151523',  // new — for raised cards
  border: '#252538',             // was #1f1f2e — more visible
  'border-strong': '#3b3b55',    // new — active/focus emphasis
  primary: '#7c3aed',
  'primary-light': '#a855f7',
},
```

### T3: Update index.css — body font + base styles

Update body font-family to Plus Jakarta Sans. Improve scrollbar. Add `font-feature-settings`
for better rendering.

```css
body {
  font-family: 'Plus Jakarta Sans', system-ui, sans-serif;
  ...
}
```

## Acceptance Criteria

- [ ] Plus Jakarta Sans visible in browser (body text different from Inter)
- [ ] `font-display` Tailwind class produces Space Grotesk
- [ ] Dashboard cards have visibly lifted surface against background
- [ ] Border lines between cards and page are clearly visible
- [ ] `npm run typecheck` passes
