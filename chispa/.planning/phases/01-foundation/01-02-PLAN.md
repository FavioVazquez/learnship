# Plan 01-02: Root Dev Script + Production Integration

<objective>
Create the root `package.json` that orchestrates both packages via `concurrently`. Wire the `dev`, `build`, `start`, and `typecheck` scripts. Verify that `npm run dev` starts both servers, the Vite proxy forwards `/api/*` to Express, and the health endpoint is reachable from both ports. Verify the production build and static serving work.
</objective>

## Context

This plan depends on Plan 01-01 (both packages scaffolded with their own `package.json` and all deps installed). The root `package.json` only owns `concurrently` as a devDependency — it is not a workspace root, just a script runner.

The production static serving path `path.join(process.cwd(), '../client/dist')` in `server/src/index.ts` requires that `npm start` be invoked with CWD = `server/`. The root `start` script achieves this via `cd server && npm start`. **Do not change this to `node server/dist/index.js` from the project root** — that would break the static file path.

## Tasks

<task id="01-02-01">
<title>Create root package.json with concurrently orchestration</title>
<files>
- package.json
</files>
<action>
Create the root `package.json`:

```json
{
  "name": "chispa",
  "version": "0.1.0",
  "private": true,
  "scripts": {
    "dev": "concurrently \"npm run dev:server\" \"npm run dev:client\"",
    "dev:server": "cd server && npm run dev",
    "dev:client": "cd client && npm run dev",
    "build": "cd client && npm run build && cd ../server && npm run build",
    "start": "cd server && npm start",
    "typecheck": "cd server && npm run typecheck && cd ../client && npm run typecheck"
  },
  "devDependencies": {
    "concurrently": "^8.2.0"
  }
}
```

Then run:
```bash
cd /home/user/learnship/chispa && npm install
```
This installs `concurrently` in the root `node_modules/`.
</action>
<verify>
`node_modules/.bin/concurrently --version` exits 0.
`cat package.json | grep concurrently` shows the devDependency entry.
</verify>
<done>
Root package.json exists with correct scripts. `concurrently` installed.
</done>
</task>
