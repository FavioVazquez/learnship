## What shipped

A stateless startup idea validator: user submits an idea, Claude searches the web
with `web_search_20250305`, returns a structured analysis in <90 seconds via SSE
streaming. React + Vite frontend with animated dashboard (VerdictCard,
RiskRadarChart, CompetitorCard, MarketSnapshot, FirstSteps, ActivityFeed).
Shareable URLs via lz-string compression. API key security via `.env`, startup
validation, CORS guard.

## Key decisions

- SSE over WebSockets — simpler, fits Claude streaming API
- Claude as research agent with `web_search_20250305` — real data, not hallucinations
- lz-string URL compression — keeps shareable URLs under nginx limits
- Stateless — no database, all state in URL or in-memory

## Post-launch bugs fixed (live test 2026-05-27)

- `req.on('close')` → `res.on('close')` — request was aborting immediately after POST body parse
- `APIUserAbortError` guard — Anthropic SDK wraps native AbortError
- Text block fragmentation — `web_search` returns interleaved blocks; must join all
